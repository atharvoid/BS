# Part 1 — research, audit and redesign plan

No code changes live in this folder. Three documents, read in order:

1. **[Competitor research](01-competitor-research.md)** — what import-export,
   textile and home-product exporters actually say on their websites, the
   tactics worth adopting, the tactics to avoid, and what it means for BS.
2. **[Website audit](02-website-audit.md)** — every issue found, by area, with
   severity and status; the website rated **6.0/10** and the plan rated
   **7.5/10**, with the reasoning and a priority order for what to fix next.
3. **[Redesign plan](03-redesign-plan.md)** — the restructuring: site
   structure and navigation, the nine-section homepage, five category pages
   with the textile page as the deep one, the supporting pages, design system
   evolution, content model, SEO, measurement, and a five-phase sequence.

Part 2 (the fixes) is recorded in [`CHANGES.md`](../../CHANGES.md) and
[`VERIFICATION.md`](../../VERIFICATION.md).
